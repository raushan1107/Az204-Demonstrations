# AZ-204 Demonstrations

Hands-on demos for AZ-204 (Developing Solutions for Microsoft Azure): Resource Manager templates, Cosmos DB, App Configuration, Event Hubs, AKS, managed identity, Logic Apps, API Management, Azure Files, load balancer, CLI, PowerShell and Cloud Shell.

## What's inside

- `azure-resourcemanager-templates-*/` — ARM template demos (introduction, parameters, conditions, dependencies, nested and linked, multiple instances)
- `azure-cosmosdb-introduction/`, `azure-eventhubs-introduction/`, `azure-appconfiguration-introduction/`
- `azure-kubernetesservice-introduction/`, `azure-active-directory-managed-identity-tutorial/`, `azure-logicapps-secure-blob-connectivity/`
- `azure-api-management-introduction/`, `azure-files-introduction/`, `azure-load-balancer-introduction/`, `azure-cli-introduction/`, `azure-powershell-introduction/`

## How to use

Each folder is a self-contained demo; follow the files inside with an Azure subscription.
